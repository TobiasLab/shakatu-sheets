# Item icon sources

These Black Desert Online item icons were retrieved from the Garmoth asset server using the drop paths returned by its
grind-tracker API:

- https://api.garmoth.com/api/external/grind-tracker
- https://assets.garmoth.com/

Retrieved on 2026-08-30 for Garmoth grind spots 194, 200, 201, 213, 214, and 215. The project license does not assert
ownership of the underlying game artwork.
