# Buff icon sources

The Black Desert Online buff icons in this directory were retrieved from the Garmoth asset server using the icon paths
returned by its grind-tracker API. `scripts/sync-grind-buffs.mjs` downloads them:

- https://api.garmoth.com/api/external/grind-tracker
- https://assets.garmoth.com/img/
